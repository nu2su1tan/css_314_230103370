### Analysis

**Where does the contention drop?** On this M2 the cache line is 128 bytes, so I expected the drop at stride = 16 (128 bytes). In my measurements I did not see a sharp drop. All times are between 457 and 477 ms. Strides 16 and 32 are about 4% faster than stride 1, but this is the same size as the noise (IQR is 6 to 14 ms), so I do not count it as a real effect.

**Why not?** The worker loop is written in pure Python. One iteration takes about 125 ns (2029 ms for 16 million steps with p = 1). This is slow compared with the delay of cache coherence between cores, so the interpreter hides it. The writes to the shared cache line are too rare to create strong contention.

**How does e(p) change with p?**
- For stride = 1: e(p) is 0.040, 0.060, 0.148 for p = 2, 4, 8.
- For stride = 16: e(p) is 0.054, 0.064, 0.126 for p = 2, 4, 8.
- Both curves are small and flat up to p = 4, and both jump at p = 8. Stride = 1 is a little higher at p = 8 (0.148 against 0.126), which is the direction that false sharing would give, but the gap is small and close to the noise level.

**Conclusion.** The strong rise of e(p) at p = 8 appears for both strides, so it is not caused mainly by false sharing. It comes from the M2 design: 4 fast P-cores and 4 slower E-cores. Every worker gets the same amount of work, so the slow E-core workers decide the total time. This is why Sp stays near 3.9 to 4.3 at p = 8 and not near 8.

### Tile sweep (Variant 3)

| BS | Median (ms) | GFLOP/s | W_tile (KB) | I_tiled (FLOP/B) | Max diff vs V2 |
|---|---|---|---|---|---|
| 8 | 430.4 | 0.0780 | 1.5 | 0.67 | 0.0e+00 |

| 128 | 413.2 | 0.0812 | 384.0 | 10.67 | 0.0e+00 |

Best tile: BS* = 64, 0.0847 GFLOP/s. The check max |C3 - C2| < 1e-9 passed for every BS.

### Analysis

**BS* against the caches.** The tile for BS* = 64 is 96 KB. It fits in the L1d of a P-core (128 KB) but not in the L1d of an E-core (64 KB). BS = 8, 16 and 32 (1.5, 6 and 24 KB) fit in both. BS = 96 and 128 (216 KB and 384 KB) fit only in L2. The whole problem (1.57 MB) already fits in the 16 MB L2 of a P-core.

**Blocking did not help much.** BS = 32 and BS = 64 are practically the same (0.0846 and 0.0847 GFLOP/s), and the whole sweep is inside about 8%. In pure Python, the interpreter cost per inner iteration (about 100 ns) is much bigger than a cache miss, so a better cache pattern does not make the code faster. BS* = 64 is the best number on paper, but the sweep is almost flat.

**Why is Variant 2 slower than Variant 1?** In C the i-k-j order is usually faster. Here Variant 2 reads and writes `C[i*N + j]` in every inner step, while Variant 1 keeps the sum in a local variable. In Python this extra memory work costs more than the better access pattern saves.

### Roofline mapping

- Variants 1 and 2 (no reuse): about 2 FLOP per 16 bytes = 0.125 FLOP/Byte. This is left of the ridge point (0.481), so the model says they are memory-bound.
- Variant 3 at BS* = 64: I = 5.33 FLOP/Byte. This is right of the ridge point, so the model says it is compute-bound.
- In reality all three points are at 0.085 to 0.099 GFLOP/s, which is only about 11 to 13% of P_sustained. They are far below both roofs because the interpreter overhead is the real limit.

## 5. Phase 4: Skewed workload and scheduling

N = 8000, p = 8, cost of item i is K(i) = 1 + floor((i/40)^2).

| Strategy | T_wall (ms) | lambda |
|---|---|---|
| Block static | 3505.9 | 2.462 |
| Cyclic static | 2310.0 | 1.019 |
| Dynamic C = 1 | 2243.3 | 1.006 |
| Dynamic C = 8 | 2326.6 | 1.009 |
| Dynamic C = 64 | 2264.2 | 1.064 |
| Dynamic C = 512 | 2718.7 | 1.469 |

Optimal chunk size: **C\* = 1** (lowest T_wall of the dynamic runs, and the lowest of all strategies).

### Analysis

- **Block static is the worst** (3506 ms, lambda = 2.46). The cost grows with i^2, so the last block holds about 33% of all work. The theory gives lambda of about 2.64, and I measured 2.46.
- **Cyclic static** balances the load well (lambda = 1.02) without any synchronization, because the cost changes smoothly. It is only about 3% slower than the best dynamic run.
- **Dynamic C = 1** has the best balance (lambda = 1.006) and the lowest time. C = 1, 8 and 64 are within about 4% of each other, so they are practically equal.
- **C = 1 (synchronization contention).** Every item needs the lock on the shared counter. Here this is cheap, because one item costs about 2 ms on average, so the lock time is small. With cheaper items, C = 1 would become slow because all workers wait for the same lock.
- **C = 512 (tail imbalance).** There are only about 16 chunks for 8 workers. The heaviest items are at the end, so the last chunks go to a few workers and the others wait. This gives lambda = 1.47 and the time goes up to 2719 ms.
- **Choice of C\*.** C = 1 has the lowest time in my runs. In a workload with cheaper items, a middle value (8 to 64) is safer, because it avoids both the lock cost and the tail imbalance.

## 6. Short summary

1. The M2 has 4 P-cores and 4 E-cores and a 128-byte cache line. This explains most results (speedup stays near 4 to 4.6 with 8 processes).
2. A clear false sharing drop was not visible, because the pure-Python loop is too slow compared with cache coherence delays.
3. Amdahl's cap (45.4) is not the limit. The slower E-cores and pool overhead are.
4. Roofline numbers are limited by process start-up and the Python interpreter, and cache blocking gives no clear gain in Python.
5. For the skewed workload, block static is the worst, and dynamic scheduling with small chunks (or cyclic static) works best.

### harness.py
```python
from dataclasses import dataclass
import multiprocessing as mp
import time
from typing import Callable

@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float

def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode("utf-8"):
        h = ((h ^ b) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h

def run_benchmark(fn: Callable[[], None], warmup: int = 2, runs: int = 7) -> BenchStats:
    for _ in range(warmup):
        fn()
    samples = []
    for _ in range(runs):
        t0 = time.perf_counter_ns()
        fn()
        samples.append((time.perf_counter_ns() - t0) / 1e6)
    samples.sort()
    med = samples[runs // 2]
    return BenchStats(samples[0], med, samples[(3 * runs) // 4] - samples[runs // 4])

def emit_verify_tag(phase: str, seed: int, m1: float, m2: float) -> str:
    hw = mp.cpu_count()
    sig = fnv1a_hash(f"{phase}|{seed}|{hw}|{m1:.4f}|{m2:.4f}")
    return f"VERIFY_HASH[{phase}]: {sig:016X} (P_log={hw})"
```

```python
# usage: python3 task1_falsesharing.py STUDENT_ID P_PHYS
import sys, ctypes
import multiprocessing as mp
from multiprocessing import shared_memory
from harness import run_benchmark, emit_verify_tag

M = 16_000_000

def fs_worker(shm_name, slot_idx, iters):
    shm = shared_memory.SharedMemory(name=shm_name)
    arr = (ctypes.c_uint64 * 512).from_buffer(shm.buf)
    acc = arr[slot_idx]
    for i in range(iters):
        acc = (acc * 6364136223846793005 + (i | 1)) & 0xFFFFFFFFFFFFFFFF
        arr[slot_idx] = acc
    del arr
    shm.close()

def run_once(p, stride):
    shm = shared_memory.SharedMemory(create=True, size=4096)
    try:
        procs = [mp.Process(target=fs_worker, args=(shm.name, t * stride, M // p))
                 for t in range(p)]
        for pr in procs: pr.start()
        for pr in procs: pr.join()
    finally:
        shm.close()
        shm.unlink()

def bench(p, stride):
    return run_benchmark(lambda: run_once(p, stride), warmup=1, runs=5)

def karp_flatt(sp, p):
    return (1 / sp - 1 / p) / (1 - 1 / p)

if __name__ == "__main__":
    sid, pphys = int(sys.argv[1]), int(sys.argv[2])
    plog = mp.cpu_count()

    print("== Stride sweep, p =", pphys)
    print("stride | bytes | median_ms | iqr_ms | Mops/s")
    med = {}
    for stride in [1, 2, 4, 8, 16, 32]:
        st = bench(pphys, stride)
        med[stride] = st.median_ms
        mops = M / (st.median_ms / 1000) / 1e6
        print(f"{stride:6d} | {stride*8:5d} | {st.median_ms:9.1f} | {st.iqr_ms:6.1f} | {mops:8.2f}")

    ps = [1]
    while ps[-1] * 2 <= plog:
        ps.append(ps[-1] * 2)
    if ps[-1] != plog:
        ps.append(plog)

    for stride in [1, 16]:
        print(f"\n== Process scaling, stride = {stride}")
        print("p | median_ms | Sp | Ep | e(p)")
        t1 = None
        for p in ps:
            st = bench(p, stride)
            if t1 is None:
                t1 = st.median_ms
            sp = t1 / st.median_ms
            ep = sp / p
            e = f"{karp_flatt(sp, p):.4f}" if p >= 2 else "-"
            print(f"{p:2d} | {st.median_ms:9.1f} | {sp:5.2f} | {ep:5.2f} | {e}")

    print()
    print(emit_verify_tag("PHASE1", sid, med[1], med[16]))
```

### task2_scaling.py
```python
# usage: python3 task2_scaling.py STUDENT_ID P_PHYS
import sys, math, statistics
import time
import multiprocessing as mp
from harness import emit_verify_tag

def stage_a(n):
    acc = 0.0
    for i in range(int(0.05 * n)):
        x = i * 1e-3
        for _ in range(5):                 # 5 * (sin + sqrt) = 10 ops
            x = math.sqrt(math.sin(x) + 2.0)
        acc += x
    return acc

def stage_b_chunk(args):
    s, e = args
    acc = 0.0
    for i in range(s, e):
        x = i * 1e-6
        for _ in range(10):                # 10 * (fma + sin + sqrt) = 30 ops
            x = x * 0.999 + 0.1
            x = math.sin(x)
            x = math.sqrt(x * x + 1.0)
        acc += x
    return acc

def trial(pool, n, p):
    t0 = time.perf_counter()
    stage_a(n)
    ta = time.perf_counter() - t0
    k = p * 4
    chunks = [(j * n // k, (j + 1) * n // k) for j in range(k)]
    pool.map(stage_b_chunk, chunks)
    total = time.perf_counter() - t0
    return total * 1000, ta * 1000

def measure(n, p, reps=3):
    pool = mp.Pool(processes=p)
    try:
        trial(pool, n, p)                  # warmup
        tot, ta = [], []
        for _ in range(reps):
            a, b = trial(pool, n, p)
            tot.append(a); ta.append(b)
    finally:
        pool.close(); pool.join()
    return statistics.median(tot), statistics.median(ta)

if __name__ == "__main__":
    sid, pphys = int(sys.argv[1]), int(sys.argv[2])
    plog = mp.cpu_count()

    print("== Strong scaling, N = 1.2e6")
    print("p | T_ms | S | E")
    strong = {}
    ta1 = None
    for p in range(1, plog + 1):
        t, ta = measure(1_200_000, p)
        strong[p] = t
        if p == 1:
            ta1 = ta
        sp = strong[1] / t
        print(f"{p:2d} | {t:9.1f} | {sp:5.2f} | {sp/p:5.2f}")
    s = ta1 / strong[1]
    s_plog = strong[1] / strong[plog]
    print(f"s = {s:.4f}, Amdahl cap 1/s = {1/s:.2f}, observed S(Plog) = {s_plog:.2f}")
    if pphys < plog:
        s1 = strong[1] / strong[pphys]
        s2 = strong[1] / strong[pphys + 1]
        print(f"Marginal speedup Pphys -> Pphys+1: {s1:.2f} -> {s2:.2f} (delta {s2 - s1:+.2f})")

    print("\n== Weak scaling, N0 = 2e5 per worker")
    print("p | T_ms | E_weak | alpha | S_Gustafson")
    weak1 = None
    sg_plog = None
    for p in range(1, plog + 1):
        t, ta = measure(p * 200_000, p)
        if p == 1:
            weak1 = t
        alpha = ta / t
        sg = p - alpha * (p - 1)
        sg_plog = sg
        print(f"{p:2d} | {t:9.1f} | {weak1/t:6.3f} | {alpha:.4f} | {sg:6.2f}")

    print()
    print(emit_verify_tag("PHASE2", sid, s_plog, sg_plog))
```

```python
# usage: python3 task3_roofline_gemm.py STUDENT_ID P_PHYS
import sys, time
import multiprocessing as mp
from multiprocessing import shared_memory
from harness import run_benchmark, emit_verify_tag

SZ = 64 * 10**6
N = 256
NN = N * N

# ---------- 3A ----------
def copy_worker(na, nb, s, e):
    a = shared_memory.SharedMemory(name=na)
    b = shared_memory.SharedMemory(name=nb)
    a.buf[s:e] = b.buf[s:e]
    a.close(); b.close()

def fma_worker(iters):
    a0=a1=a2=a3=a4=a5=a6=a7=1.0
    a8=a9=a10=a11=a12=a13=a14=a15=1.0
    b = 1.0000001
    c = 1e-9
    for _ in range(iters):
        a0 = a0*b + c
        a1 = a1*b + c
        a2 = a2*b + c
        a3 = a3*b + c
        a4 = a4*b + c
        a5 = a5*b + c
        a6 = a6*b + c
        a7 = a7*b + c
        a8 = a8*b + c
        a9 = a9*b + c
        a10 = a10*b + c
        a11 = a11*b + c
        a12 = a12*b + c
        a13 = a13*b + c
        a14 = a14*b + c
        a15 = a15*b + c
    return a0 + a1 + a2 + a3 + a4 + a5 + a6 + a7 + a8 + a9 + a10 + a11 + a12 + a13 + a14 + a15

def run_copy(na, nb, p):
    procs = []
    for t in range(p):
        s, e = t * SZ // p, (t + 1) * SZ // p
        procs.append(mp.Process(target=copy_worker, args=(na, nb, s, e)))
    for pr in procs: pr.start()
    for pr in procs: pr.join()

def run_fma(p, iters):
    procs = [mp.Process(target=fma_worker, args=(iters,)) for _ in range(p)]
    for pr in procs: pr.start()
    for pr in procs: pr.join()

# ---------- 3B ----------
def gemm_worker(name, variant, bs, r0, r1):
    shm = shared_memory.SharedMemory(name=name)
    mv = shm.buf.cast('d')
    A = mv[0:NN]; B = mv[NN:2*NN]; C = mv[2*NN:3*NN]
    if variant == 1:
        for i in range(r0, r1):
            for j in range(N):
                s = 0.0
                for k in range(N):
                    s += A[i*N + k] * B[k*N + j]
                C[i*N + j] = s
    else:
        for idx in range(r0*N, r1*N):
            C[idx] = 0.0
        if variant == 2:
            for i in range(r0, r1):
                for k in range(N):
                    a_ik = A[i*N + k]
                    for j in range(N):
                        C[i*N + j] += a_ik * B[k*N + j]
        else:
            for ii in range(r0, r1, bs):
                for kk in range(0, N, bs):
                    for jj in range(0, N, bs):
                        for i in range(ii, min(ii + bs, r1)):
                            for k in range(kk, min(kk + bs, N)):
                                a_ik = A[i*N + k]
                                for j in range(jj, min(jj + bs, N)):
                                    C[i*N + j] += a_ik * B[k*N + j]
    A.release(); B.release(); C.release(); mv.release()
    shm.close()

def run_gemm(name, variant, bs, p):
    procs = []
    for t in range(p):
        r0, r1 = t * N // p, (t + 1) * N // p
        procs.append(mp.Process(target=gemm_worker, args=(name, variant, bs, r0, r1)))
    for pr in procs: pr.start()
    for pr in procs: pr.join()

if __name__ == "__main__":
    sid, pphys = int(sys.argv[1]), int(sys.argv[2])

    # --- 3A bandwidth ---
    sa = shared_memory.SharedMemory(create=True, size=SZ)
    sb = shared_memory.SharedMemory(create=True, size=SZ)
    st = run_benchmark(lambda: run_copy(sa.name, sb.name, pphys), warmup=2, runs=7)
    bw = 2 * 64 * 10**6 / ((st.median_ms / 1000) * 1e9)
    sa.close(); sa.unlink(); sb.close(); sb.unlink()
    print(f"BW_sustained = {bw:.2f} GB/s (median {st.median_ms:.1f} ms)")

    shm = shared_memory.SharedMemory(create=True, size=3 * NN * 8)
    mvp = shm.buf.cast('d')

        mvp[i] = ((i * 7) % 13) / 13.0
        mvp[NN + i] = ((i * 5) % 11) / 11.0
    flops = 2 * N**3

    def gflops(ms):
        return flops / ((ms / 1000) * 1e9)

        return mvp[2*NN:3*NN].tolist()

    s1 = run_benchmark(lambda: run_gemm(shm.name, 1, 0, pphys), warmup=1, runs=3)
    g1 = gflops(s1.median_ms)

    print("\nBS | median_ms | GFLOP/s | W_tile(KB) | I_tiled | maxdiff vs V2")

        c3 = get_c()

        assert diff < 1e-9, f"mismatch for BS={bs}: {diff}"
        g3 = gflops(s3.median_ms)

        print(f"{bs:3d} | {s3.median_ms:9.1f} | {g3:7.4f} | {wtile:10.1f} | {bs/12:7.2f} | {diff:.1e}")
        if g3 > best_g:
```

### task4_scheduling.py
```python
# usage: python3 task4_scheduling.py STUDENT_ID P_PHYS
import sys, math, time
import multiprocessing as mp
from harness import emit_verify_tag

N = 8000

def heavy(i):
    k = 1 + (i * i) // 1600          # floor((i/40)^2)
    x = 0.1 * (i % 7 + 1)
    for _ in range(k):
        x = math.sqrt(abs(math.sin(x) * math.cos(x))) + 0.1
    return x

def worker(t, p, mode, chunk, counter, times):
    t0 = time.perf_counter()
    if mode == "block":
        for i in range(t * N // p, (t + 1) * N // p):
            heavy(i)
    elif mode == "cyclic":
        for i in range(t, N, p):
            heavy(i)
    else:
        while True:
            with counter.get_lock():
                s = counter.value
                counter.value = s + chunk
            if s >= N:
                break
            for i in range(s, min(s + chunk, N)):
                heavy(i)
    times[t] = time.perf_counter() - t0

def run(p, mode, chunk=1, reps=3):
    results = []
    for _ in range(reps):
        counter = mp.Value('i', 0)
        times = mp.Array('d', p)
        procs = [mp.Process(target=worker, args=(t, p, mode, chunk, counter, times))
                 for t in range(p)]
        t0 = time.perf_counter()
        for pr in procs: pr.start()
        for pr in procs: pr.join()
        wall = (time.perf_counter() - t0) * 1000
        tw = list(times)
        lam = max(tw) / (sum(tw) / p)
        results.append((wall, lam))
    results.sort()
    return results[reps // 2]        # median by wall time

if __name__ == "__main__":
    sid, pphys = int(sys.argv[1]), int(sys.argv[2])
    print("strategy | T_wall_ms | lambda")
    t_block, lam = run(pphys, "block")
    print(f"block static | {t_block:9.1f} | {lam:.3f}")
    t_cyc, lam = run(pphys, "cyclic")
    print(f"cyclic static | {t_cyc:9.1f} | {lam:.3f}")

    best_c, best_t = None, float("inf")
    for c in [1, 8, 64, 512]:
        t, lam = run(pphys, "dynamic", c)
        print(f"dynamic C={c} | {t:9.1f} | {lam:.3f}")
        if t < best_t:
            best_t, best_c = t, c
    print(f"C* = {best_c}")
    print(emit_verify_tag("PHASE4", sid, t_block, best_t))
```
